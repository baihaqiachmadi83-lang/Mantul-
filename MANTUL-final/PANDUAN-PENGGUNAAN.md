# 📖 Panduan Penggunaan MANTUL
**Mandiri Tunas English Learning** — Belajar Bahasa Inggris Interaktif

---

## 🚀 Cara Memulai

### 1. Buka Aplikasi
- Buka file `index.html` melalui browser (disarankan **Chrome / Edge**)
- Atau akses link hosting jika sudah di-deploy (misal GitHub Pages)

### 2. Masukkan Nama
Saat pertama kali membuka, kamu akan diminta memasukkan **nama lengkap**. Nama ini akan digunakan untuk mencetak **sertifikat** di akhir kursus.

> 💡 **Tips:** Nama bisa diganti kapan saja dengan menekan tombol ✏️ di samping nama di halaman utama.

### 3. Mulai Belajar!
Kamu akan masuk ke **halaman utama (Dashboard)** yang menampilkan peta belajar.

---

## 📚 Alur Belajar

Aplikasi MANTUL memiliki **3 unit utama + 1 ujian akhir** yang harus diselesaikan secara berurutan:

```
Unit 1: Things Around Me (Vocabulary)
        ⬇️
Unit 2: Speak Up! (Speaking)
        ⬇️
Unit 3: Read the Signs (Reading)
        ⬇️
🏆 Final Test (Ujian Akhir)
```

### 🔒 Sistem Unlock
- **Unit 1** langsung terbuka
- **Unit 2** terbuka setelah Unit 1 selesai
- **Unit 3** terbuka setelah Unit 2 selesai
- **Final Test** terbuka setelah semua unit selesai

> Jika ingin **melewati sistem lock** untuk demo/presentasi, klik tombol **🔓 Unlock** di navbar atau gunakan **🎮 Demo Mode** saat modal unlock muncul.

## 📖 Apa Isi Setiap Unit?

### Unit 1 — Things Around Me (Kosakata)
Belajar kosakata sehari-hari: benda di sekitar, makanan, uang, aktivitas.
- 📗 **6 topik materi** — baca dan dengarkan pelafalan
- ✍️ **Latihan soal** — kuis interaktif
- 🎮 **Game** — permainan untuk mengasah ingatan

### Unit 2 — Speak Up! (Berbicara)
Berlatih berbicara dan percakapan dalam situasi nyata.
- 🎙️ **4 topik materi** — dialog, pelafalan, ekspresi
- 🔊 **Text-to-Speech** — dengarkan contoh pelafalan (klik tombol 🔊)
- ✍️ **Latihan & Game** — kuis percakapan

### Unit 3 — Read the Signs (Membaca)
Meningkatkan kemampuan membaca teks publik dalam bahasa Inggris.
- 📖 **4 topik materi** — rambu, label, pengumuman
- 🖼️ **Membaca gambar nyata** — latihan berbasis visual
- ✍️ **Latihan & Game** — kuis pemahaman bacaan

### 🏆 Final Test (Ujian Akhir)
- 📝 **50 soal campuran** dari 3 unit (Vocabulary + Speaking + Reading)
- ⏱️ Dikerjakan sekaligus
- 🎓 Setelah selesai, kamu mendapat **Sertifikat** yang bisa dicetak!

## 🎯 Setiap Unit Punya 3 Fase

Setiap unit mengikuti pola yang sama:

| Fase | Ikon | Apa yang dilakukan |
|---|---|---|
| **1. Material** | 📖 | Baca dan pelajari materi |
| **2. Exercise** | ✍️ | Jawab kuis latihan (ada feedback langsung) |
| **3. Game** | 🎮 | Mainkan game untuk mengasah pemahaman |

Kamu harus menyelesaikan setiap fase untuk lanjut ke fase berikutnya.

---

## 💾 Tentang Penyimpanan Data

- Semua progress disimpan di **browser kamu** (localStorage)
- **Tidak perlu login** atau membuat akun
- Data tetap tersimpan selama kamu tidak menghapus data browser
- Aplikasi bisa dipakai **offline** setelah dibuka pertama kali (PWA)

---

## 📱 Install di HP (Add to Home Screen)

MANTUL adalah **Progressive Web App (PWA)** — bisa di-install di HP seperti aplikasi biasa:

1. Buka MANTUL di **Chrome** (HP Android)
2. Ketuk menu ⋮ (titik tiga) di pojok kanan atas
3. Pilih **"Add to Home Screen"** atau **"Install App"**
4. MANTUL akan muncul sebagai ikon di layar HP kamu!

## ❓ FAQ (Pertanyaan Umum)

**Q: Apakah butuh internet?**
A: Hanya saat pertama kali membuka. Setelah itu bisa dipakai offline.

**Q: Bagaimana kalau progress hilang?**
A: Progress tersimpan di browser. Jangan hapus data/cache browser.

**Q: Bisa dipakai di HP?**
A: Bisa! Desainnya responsive dan sudah dioptimalkan untuk mobile.

**Q: Berapa lama menyelesaikan semua unit?**
A: Sekitar 2-4 jam jika dikerjakan fokus, atau bisa dicicil harian.

**Q: Sertifikat bisa dicetak?**
A: Bisa! Setelah Final Test, buka halaman sertifikat → tekan Ctrl+P untuk cetak.
